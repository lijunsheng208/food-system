## 结果边界

本次是 1 次摘要生成、31 条人工构造且非随机抽样的可回答事实。Wilson 95% 区间按二项比例公式计算，仅作名义不确定性参考；由于样本不是从线上对话随机抽取，不能解释为线上总体置信区间，也不能证明摘要策略普遍更优。100% 仅表示标注词组在本次摘要上下文中全部命中。实体归属、语义等价、否定/关系、摘要幻觉均未由自动词面指标充分验证；更正安全率把任何旧值字面出现都保守判为不安全，需人工审查语境。Token 是字符长度估算，不是模型 tokenizer 的精确计数。
