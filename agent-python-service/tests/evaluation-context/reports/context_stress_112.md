## 结果边界

本次是 1 次摘要生成、110 条高真实性合成且非随机抽样的可回答事实。它不是线上真实用户数据，不能替代脱敏生产会话评测。Wilson 95% 区间按二项比例公式计算，仅作名义不确定性参考；由于样本不是从线上对话随机抽取，不能解释为线上总体置信区间，也不能证明摘要策略普遍更优。词面信息单元保留率不能证明语义无损；关系完整率要求标注的核心实体和值在同一摘要条目内共现，仍不能识别隐含关系、否定或模型幻觉。更正安全率把任何旧值字面出现都保守判为不安全，需人工审查语境。Token 是字符长度估算，不是模型 tokenizer 的精确计数。
